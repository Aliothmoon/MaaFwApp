# MaaFw Mobile UI Design

## 设计目标

这是一个任务驱动的移动端工具界面。视觉参考现代对话类 App 的克制感，但不复制任何品牌组件：内容优先、黑白灰为主、层级依靠留白和字重表达，减少装饰性色彩与阴影。

任务队列是产品的核心结构。视觉调整不得把任务列表改造成仪表盘、卡片瀑布流或营销页，也不得隐藏任务选择、详细设置和删除操作。

## 设计原则

1. **移动端优先**：主要验证宽度为 360–480px，所有交互目标至少 44px。
2. **中性界面**：黑、白、灰承担内容与交互层级；绿色只表达连接或运行状态。
3. **结构稳定**：保留首页、任务、设置三层导航和任务队列式布局。
4. **少量圆角**：卡片、控件、标签使用不同但固定的圆角等级，不把所有元素都做成胶囊。
5. **无装饰渐变**：不使用装饰性渐变；阴影只在确有浮层关系时使用。
6. **状态清晰**：选中、禁用、运行和删除确认必须仅凭视觉即可辨认。

## 颜色

| Token | 值 | 用途 |
|---|---:|---|
| `canvas` | `#ffffff` | 页面、卡片、输入控件 |
| `parchment` | `#f7f7f8` | 应用背景、弱分区 |
| `pearl` | `#f3f3f3` | 按压、悬停、次级底色 |
| `ink` | `#212121` | 主文字、主要按钮、选中态 |
| `ink-soft` | `#424242` | 次级正文 |
| `muted` | `#6b6b6b` | 说明文字、未选中图标 |
| `body-muted` | `#b4b4b4` | 深色区域次级文字、禁用态 |
| `hairline` | `#e5e5e5` | 卡片和导航分割线 |
| `divider` | `#ececec` | 列表内部弱分割 |
| `status-green` | `#10a37f` | 仅用于在线、连接、运行状态 |
| `focus` | `#000000` | 键盘焦点环 |

### 色彩规则

- 主要交互使用 `ink`，不引入第二套品牌色。
- `status-green` 是语义状态色，不用于普通按钮、标签或装饰。
- 禁用态使用透明度和灰色表达，仍需保持文字可读。
- 深色预览区域使用 `#212121`，其上的主要文字为白色。

## 字体

项目不下载或捆绑专用字体，使用设备原生 UI 字体：

```css
font-family: ui-sans-serif, system-ui, -apple-system,
  BlinkMacSystemFont, "Segoe UI", sans-serif;
```

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---:|---|
| 页面标题 | 18px / 1.25 | 600 | 顶部导航标题 |
| 内容标题 | 20–32px / 1.15–1.25 | 600 | 首页状态、设置页标题 |
| 正文 | 16px / 1.5 | 400 | 默认正文 |
| 控件文字 | 13–15px / 1.35 | 400–500 | 按钮、列表、Tab |
| 辅助文字 | 11–12px / 1.5 | 400–500 | 描述、计数、分组标签 |

标题使用轻微负字距 `-0.025em`；正文使用 `-0.011em`。避免 700 以上的粗重字形。

## 圆角

| Token | 值 | 用途 |
|---|---:|---|
| `none` | `0px` | 分割线、满宽媒体 |
| `xs` | `6px` | 复选框、小标签 |
| `sm` | `10px` | 小按钮、Tab 焦点、确认按钮 |
| `md` | `12px` | 输入框、选择器、设置项 |
| `lg` | `16px` | 任务卡片、主要操作按钮、底部抽屉 |
| `full` | `9999px` | 筛选标签、Switch、圆形图标按钮 |

### 圆角规则

- 同一组件的默认、按压、禁用状态必须保持相同圆角。
- 开始和停止按钮统一使用 `lg`，不得继承临时工具类圆角。
- 标签和 Switch 可使用 `full`；普通输入框与卡片不得使用胶囊圆角。
- 嵌套表面的内层圆角应小于外层圆角。

## 间距与布局

- 基础间距：4、8、12、16、20、24、32px。
- 页面水平边距：移动端 16px；标题栏可使用 20px 左边距。
- 列表间距：8px；卡片内边距：12–16px。
- 顶部导航高度：56px。
- 底部主操作区保持固定，使用安全区 `env(safe-area-inset-bottom)`。
- 宽屏只增加列数与内容宽度，不改变功能层级。

## 组件规范

### 任务列表

- 保持队列顺序和单列结构；平板可增加列数。
- 列表标题区提供“添加任务”入口，任务目录以底部抽屉呈现并按选择顺序追加。
- 每行依次包含：选择框、任务信息、可选项箭头、删除按钮。
- 删除按钮始终占有 44×44px 点击区域，运行中禁用。
- 删除采用二次点击确认；确认后焦点移动到相邻任务或列表标题。

### Switch

- 点击区域为 46×44px，可视轨道为 46×27px。
- 圆点为 21px，左右各保留 3px；关闭位移为 0，开启位移为 19px。
- 圆点必须设置明确的 `left: 3px`，不得依赖绝对定位元素的静态位置。
- 轨道和圆点使用 180ms 动画；减少动态效果时关闭动画。

### 主要操作

- 开始任务：深色实心按钮，白色文字。
- 停止任务：白色描边按钮，深色文字；仅运行时启用。
- 两个按钮高度至少 44px，统一 `lg` 圆角。

### 输入与选择器

- 高度至少 44px，使用 `md` 圆角和 1px `hairline` 边框。
- 焦点使用 2px 黑色外轮廓，不以颜色变化作为唯一提示。

### 底部导航

- 白色半透明背景、细分割线、无阴影。
- 激活项使用 `ink`，未激活项使用 `muted`。
- 图标加文字，单项点击高度至少 48px。

## 动效与无障碍

- 按压缩放最大为 `0.95`，时长 100ms。
- 状态切换时长 150–180ms；底部抽屉可使用 250–350ms。
- 支持 `prefers-reduced-motion: reduce`。
- 所有图标按钮提供 `aria-label`。
- 键盘焦点必须可见，禁用控件不得响应指针事件。
